# Critter Cap – Pip's Pocket Critters

A short top-down critter-catching adventure built on the
[evogine](https://github.com/Dye-Entertainment/evogine) engine. Pip picks a partner critter,
explores the tall grass of the Rootwood, shrinks down to Thimblewick and heads into Root Hollow
to catch Bramblord, the critter that swallowed the Sunstone's light. Capo, a talking acorn cap,
pops off spare caps that Pip throws to catch wild critters.

It started from [Small Cap](https://github.com/Dye-Entertainment/small-cap) and reuses its maps,
characters and art. All art, maps, sound effects and music are original and generated by the
scripts in `tools/`.

## Controls

| Action                         | Keyboard                    | Gamepad   |
|--------------------------------|-----------------------------|-----------|
| Move                           | Arrows / WASD               | D-pad     |
| Talk / confirm                 | Z / J / Space               | A         |
| Cancel / hold to run           | X / K / C / Shift           | B / X     |
| Team and Critterdex            | Enter / P                   | Start     |

On phones and tablets the browser version shows a touch D-pad with A, B and START buttons
(`?touch=1` / `?touch=0` in the address forces them on or off).

## How it plays

- **Tall grass** hides wild critters; in Root Hollow they can jump out anywhere.
- **Battles** are turn based: FIGHT, CAP, TEAM or RUN. Moves have types:
  FIRE beats LEAF and BUG, WATER beats FIRE, LEAF beats WATER, BUG beats LEAF,
  AIR beats BUG and LEAF.
- **Caps** catch critters. The weaker the critter, the better the odds. Mira (Hearthwood) and
  the Thimbling healer (Thimblewick) heal your team and sell 5 caps for 20 gems.
- **Trainers** challenge you when they spot you and pay gems when you win.
- Critters level up from XP and learn a third, stronger move at level 10.
- LEAF critters chew through bushes for you.
- Up to 4 critters travel with you, and your lead critter follows you around. Extra catches go
  into Capo's spare pocket.
- If every critter faints, Pip hurries back to the last healer.

## The adventure

1. **Hearthwood** – pick a partner from Elder Bram, then beat your rival Tobi.
2. **The Rootwood** – tall grass, Tobi's rematch, and Ranger Rook guarding the shrink stump.
3. **Thimblewick** – the world at bug size, with moss beds, a healer and Pipkin the trainer.
4. **Root Hollow** – a 7-room cave with block puzzles, a small key and a big key. Catch
   Bramblord to bring back the Sunstone.

## Building

The engine is a git submodule (`evogine/`).

```sh
git submodule update --init --recursive
make evogen        # builds the engine's code generator (once)
make linux         # native build -> build-linux/Release/critter-cap
make run
make web           # emscripten build (needs ~/emsdk) -> build-web/
make pages         # copies the web build to site/
make deploy        # pushes site/ to the gh-pages branch
make assets        # regenerates textures, maps, sounds and music
```

The maps in `resources/maps` are regular Tiled JSON files (tileset `resources/textures/tiles.tsj`),
so they can be opened in Tiled; `make assets` regenerates them from `tools/make_maps.py`.

The title screen, HUD, dialog boxes, starter pick, team and Critterdex, battle boxes and ending are drawn with the engine's RmlUi UI backend: `resources/ui/game.rml` and
`game.rcss` lay them out on the 240x160 screen (1dp = one game pixel) and the game fills in a
data model every frame (`src/ui/game_ui.cpp`). `tools/make_ui.py` builds the pixel font
(`resources/ui/pixel.ttf`) and the sprite sheet declarations (`sprites.rcss`) from the same
font and atlas as the game art.
Map properties `encounters` (`species:minLevel-maxLevel:weight,...`), `wild` (`grass` or
`everywhere`) and `heal` (the spawn used after a wipe-out) drive the wild critters.

### Test hooks

Environment variables for jumping around while developing:

- `CRITTERCAP_AUTOSTART=1`: skips the title screen
- `CRITTERCAP_MAP=woods`, `CRITTERCAP_SPAWN=stump`: chooses the start point
- `CRITTERCAP_POS=22.5,8.5`: sets the start position in tiles
- `CRITTERCAP_PARTY=blob_g:8,ant:6`: starts with this team (and 10 caps)
- `CRITTERCAP_CAPS=20`: sets the number of caps
- `CRITTERCAP_BATTLE=pod:5`: starts a battle right away (`legend:boss:15`,
  `trainer:blob_b:5,ant:6`)
- `CRITTERCAP_FLAGS=a,b`: sets story flags
- `CRITTERCAP_PEACE=1`: no wild encounters
- `CRITTERCAP_ENDING=1`: jumps straight to the ending
- `CRITTERCAP_INPUT="right:60 z:1 wait:30"`: scripted input (`z` confirm, `x` cancel/run)
- `CRITTERCAP_SHOTS=120,300`: saves screenshots at those ticks, then quits
